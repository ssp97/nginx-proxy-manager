## 证书帮助

### HTTP 证书

HTTP 验证类型的证书表示 Let's Encrypt 服务器会尝试通过 HTTP（而不是 HTTPS）访问您的域名。验证成功后，Let's Encrypt 会为您签发证书。

使用此方法时，您必须为域名创建一个可通过 HTTP 访问且指向此 Nginx 安装的代理服务。证书签发后，您可以修改该代理服务，使其同时处理 HTTPS 连接。但是，为了能够续期证书，该代理服务仍必须支持 HTTP 访问。

此过程_不支持_通配符域名。

### DNS 证书

DNS 验证类型的证书要求您使用 DNS 服务商插件。该插件会在您的域名下创建临时记录，随后 Let's Encrypt 会查询这些记录，以确认您是域名所有者。验证成功后，Let's Encrypt 会为您签发证书。

请求此类证书前，您无需预先创建代理服务，也无需将代理服务配置为支持 HTTP 访问。

此过程_支持_通配符域名。

### 自定义证书

使用此选项上传由您自己的证书颁发机构签发的 SSL 证书。
